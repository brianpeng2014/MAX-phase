# MAX-phase

Ti3SiC2 MAX phase 快速燒結與熱性質研究工作區。

## 專案結構

- library：文獻原檔、索引、筆記與篩選紀錄。
- data：原始數據、分析腳本、結果與圖表。
- docs/research：研究規劃、試樣與實驗設計。
- docs/reference：格式規範、事實表與參考資料。
- thesis：正式稿件、參考文獻與交付輸出。
- decisions：命名、換算及研究決策的來源紀錄。
- scripts 與 tools：研究腳本和輔助工具。
- vendor：外部方法論與模板原件。
- _legacy：唯讀舊資料。

開始工作前請先閱讀「研究側寫.md」與「AGENTS.md」。
